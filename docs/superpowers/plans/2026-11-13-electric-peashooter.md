# 电能豌豆实施计划

**Goal:** 将使用 PVZ2 原版美术、动作和攻击规则的电能豌豆接入游戏，并共用闪电芦苇等阶换色。

**Architecture:** 原版资源转换为 Godot 场景；植物攻击时钟和电球各自持有生命周期与伤害快照；数据目录和换色入口沿用现有框架。

**Tech Stack:** Godot 4.7、GDScript、PAM/ETC1/Wwise 现有转换工具。

**Spec:** `docs/superpowers/specs/2026-11-13-electric-peashooter-design.md`

## 约束

- 保留工作区已有改动，通过修改前快照筛选本次提交。
- 按仓库约定不新增、不运行测试，只进行导入、解析和静态审查。
- 不生成替代画，不重绘原版素材；等阶变化复用现有 shader。

## 任务

- [x] 提取原版本体、卡面、电球、电弧、命中素材、声音与参数，保存来源和动作事件。
- [x] 实装 `plant_052_electric_peashooter` 与独立电球：原版攻击周期、发射帧、穿透和附近放电；保留伤害归属与轮次/暂停门禁。
- [x] 接入 registry、all_cards、图鉴、背包、合成和配方掉落；冻结卡片属性沿用原接口。
- [x] 将闪电芦苇着色入口公开给电豌豆适配器，接入卡面、图鉴、本体和弹体。
- [x] 导入并解析资源，审查暂停、死亡、重复命中、相邻行、屋顶、清场和阶级重置；独立提交本次增量。

## 审查重点

1. 电球离手后母株死亡不应吞掉已发出的攻击；换轮或棋盘销毁应清理。
2. 高速和低帧率下不遗漏直击目标，不因多个受击框重复结算。
3. 邻近放电使用原版次数、距离与频率，避开魅惑、死亡和不可受击目标。
4. 展示与花园实例不参与战斗；冻结与暂停不推进待发攻击。
5. 换色不改原始贴图，图鉴/卡面切回一阶能恢复，配色参数不互相污染。

## 实施记录

- 原版素材与原生逻辑证据见 `tools/art_bake/electric_peashooter/SOURCE.md`。
- Godot 4.7.2 资源导入后重新解析，无脚本或资源错误；纯美术隔离场景已渲染五阶本体、卡图和电球。未运行游戏测试。
- 独立审查发现并修复全局掩码漏掉跳跃目标、图鉴入树时高阶配色被重置的问题；随后补齐原版待机分层音及不连重随机容器。
- 为保证提交的场景可独立加载，一并纳入现有 `AnimComponentPlayer.animation_player_path` 的最小支持；不纳入其他芦苇场景、素材、注册或音效改动。
- 项目没有能量豆入口；原版能量豆动作、弹体及声音保留作资源，当前接入的是常规战斗机制。
