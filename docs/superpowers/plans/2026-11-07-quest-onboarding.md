# 首关任务与研究室教学实现计划

**目标：** 首关普通阶段通关后开放任务，领取初次远征奖励才开放研究室并激活初次制卡。

**架构：** 任务服务区分完成前置与领奖前置；解锁从领奖状态派生。教学服务从业务状态及独立的已读节点恢复进度，UI 编排复用原生戴夫和礼盒粒子，真实操作仍通过任务/研究事务。

**技术：** Godot 4 / GDScript，现有原生资源与存档服务，不新增依赖。

**需求依据：** 本次用户指定的功能时机、六句戴夫对话及任务奖励。用户已明确确认顺序：远征领奖 → 戴夫 → 合成坚果。

## 实现步骤

- [x] 任务目录添加 first_craft，200 EXP、2000$、土豆地雷配方/植物淀粉/爆炸种子/植物纤维各一。
- [x] QuestService 添加 requires_claimed，研究室解锁只认 claimed；任务入口只认草坪普通通关。
- [x] ResearchTransaction 在同一事务内记录 card_crafted，失败恢复卡片、资产、任务及教学标记。
- [x] AdventureState 添加可向后兼容的 tutorial_steps；教学服务负责已读节点保存与回滚。
- [x] 工具栏可领奖呼吸高亮，任务领奖复用原生礼盒星屑和 prize。
- [x] 独立教学层负责解锁公告、真实按钮高亮、原生戴夫、研究室坚果配方预选。
- [x] 静态检查、Godot 导入/解析与界面预览；按 AGENTS.md 不新增或运行测试。

## 检查重点

- 远征 complete 时研究室仍锁定，claimed 才激活后继任务。
- 保存失败不发奖、不开放研究室、不记成功制卡，不消耗教学节点。
- 重复领奖、切档、切场、窗口关闭不留下对话、声音接管或过期按钮引用。
- 已有存档不重复发奖；新任务不会用此前历史合成直接完成。
- 礼盒只提取粒子，不运行原礼盒自动拾取和花园发奖脚本。
