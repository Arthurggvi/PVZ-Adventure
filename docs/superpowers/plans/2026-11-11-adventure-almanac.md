# 冒险图鉴实施计划

> 使用 executing-plans 在当前工作区实施；遵循 AGENTS.md，不新增或运行测试。

**目标：** 将底部卡组占位改为冒险图鉴，物种获得或实战遇到一次即可查看 1–5 阶。

**设计：** 复用背包木框、羊皮纸、按钮和角色静态预览。植物/僵尸分类、可滚动目录、详情及五阶切换。独立于原版图鉴。只保存发现记录，名称、能力、属性倍率和外观从现有注册表、转职目录、僵尸阶级目录及美术入口读取，不维护第二份角色列表。植物展示各阶所有分支，未配置能力明确提示。未来沿同一配置入口扩充时自动显示。

**边界：** 旧档补录持有植物；不凭关卡名单推测历史遇敌。展示实例不触发发现。删除卡片保留发现记录，切档隔离。阶数与强化星数分开，不把备选分支当作同时生效。

## 实施

- [x] AdventureState 增加可选发现字段、严格校验与旧档兼容；库存获得和实战初始化接入，复用 SaveService。
- [x] 新增 almanac_data.gd，按注册表动态生成已发现目录，读取已有能力目录及基础属性。
- [x] 新增 almanac_window.gd，接入工具栏模态契约；复用已有面板、预览与阶级美术。
- [x] 检查差异、引用、发现边界、存档兼容和预览资源隔离。不运行测试。

## 审查重点

空目录、旧档、跨档、预览误解锁、同物种重复遇到、多转职分支与缺失美术。

## 结果

Godot 4.7.2 仅编辑器解析通过（退出码 0、日志无 ERROR）；git diff --check 通过。独立只读代码审查未发现重要缺陷。未运行游戏或测试。修正了辅助函数与 RefCounted.reference 的命名冲突，并同步补齐研究合成及初始赠卡的发现记录回滚。

当前僵尸范围为现有五阶系统使用的普通僵尸目录；独立僵王体系尚无对应五阶配置，未纳入。提交仅包含本次图鉴功能与用户要求的提交约定，保留用户既有改动。
