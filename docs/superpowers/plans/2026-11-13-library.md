# 图书馆实现计划

**Goal:** 接通建筑与每日售书、同阶转换、同物种升阶。

**Architecture:** 目录唯一、状态独立、事务集中、表现分离。

**Tech Stack:** Godot 4.7 / GDScript，现有库存 UI 资源。

**Spec:** `docs/superpowers/specs/2026-11-13-library-design.md`

## 约束与审查重点

遵守仓库不运行测试约定。所有新增变量及函数附中文用途注释。保持其他未提交改动。
重点审查：同书重复投入数量、四阶拒绝、保存回滚、跨日旧货位、切档与金币信号重入。

## 实施裁定

- 转换的“不同”解释为排除所有投入书 ID；同物种同阶的不同技能可混合升阶。
- 默认本机自然日，与日常任务一致；拒绝通过回拨日期领取另一批免费书籍。
- 不执行技能默认 TDD 流程，以仓库 AGENTS.md 的测试约定为准。

## 验证记录

- Godot 4.7.2 编辑器无头导入和脚本注册完成，日志无脚本错误。
- 使用隔离 APPDATA、合成展示数据渲染今日、转换、合成三页；最终渲染日志无错误，截图位于工作区外的 `_review/library-preview/`。没有交易真实玩家资产。

- 修复审查发现的切档回滚余额覆盖，以及跨日保存失败无重试入口；同步补上材料区重绘后的键盘焦点恢复。
