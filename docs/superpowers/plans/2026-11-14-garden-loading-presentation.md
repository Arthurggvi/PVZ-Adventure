# 花园加载界面实施与修订计划

**Goal:** 将 Bootstrap、场景切换和功能窗口加载统一为安静、连续的表现；正常加载不要求阅读，不增加人为等待。

**Architecture:** 继续使用现有 SceneTransition/ResourceBatch。新增只负责绘制的 LoadingPresentation；场景通过目标 metadata 交接表现快照，功能窗口复用紧凑版并平滑退出。无新增 Autoload、后台管理器或资源缓存。

**Tech Stack:** Godot 4.7.2，原生 Control/CanvasItem、轻量纹理和 Tween。插画由内建 imagegen 生成；Godot 导入限制最长边 512px。

## 视觉与交互决定

2026-11-14 修订原因：用户指出短加载中的标题、口号和阶段说明无人阅读，显得冗余且打扰。新版删去正常文案、品牌字与装饰动效；以下为当前设计，初版验收只保留历史记录。

- 全屏只保留暖墨绿背景、静态向日葵/豌豆射手插画和原版泥土/草皮进度条；不显示标题、品牌、阶段说明或百分比。
- 窗口版本保留原场景，以设计尺寸312×112的小提示显示进度条和“取消”；不显示插画或大卡片。只有失败时显示简短原因和必要的返回/重试动作。
- 场景及模态内容都在0.45秒后展开；模态遮罩也在0.45秒后才开始淡入，最高透明度12%。短请求不强制最短停留，完成时立即交接；Bootstrap原有静态首屏直接交给统一过渡。
- 移除插画漂浮、阳光呼吸、背景光点，以及`SUN`/`Bake_Soda`预加载；进度只单调平滑推进。`_process()`仅在进度或透明度变化时运行，到达目标或隐藏后停止。
- 加载中取消立即撤销业务请求，视觉可短暂淡出但不能阻挡后续输入。失败提供明确可关闭/重试动作。
- 保留原状态提交、失败回滚、档案身份校验与两帧揭幕协议。

## 公共表现接口

`scripts/ui/transitions/loading_presentation.gd` extends Control:

- `configure(compact: bool = false)`
- `set_progress(amount: float)`：单调显示，正常加载最多0.94；`finish()`允许到1，但不等待动画完成。
- `show_error(message: String)`：仅失败时显示简短说明；正常阶段没有文字接口。
- `set_content_visible(value: bool, instant: bool = false)`：只控制内容淡入，宿主仍拥有输入锁。
- `set_action(text: String, callback: Callable)`、`disable_action()`、`focus_action()`
- `snapshot() -> Dictionary`、`restore(state: Dictionary)`：仅保存`compact/displayed/target/opacity/target_opacity/error/message`，不保存业务对象或装饰动画时间。

## Review Focus

- 短请求不能为了展示插画增加等待；暂停和倍速不能改变加载动效时间。
- 源场景释放后，目标表现不能闪回空黑、进度回零或重置内容透明度。
- 取消反馈淡出后不能清掉新窗口、抢焦点或拦截底层输入。
- Bootstrap只引用512px单图和两张小加载条，不静态引用任何角色/功能场景或大型字体；正常加载不恢复品牌或说明文案。
- 保留已有project.godot及未跟踪UID；只提交本次文件，不push。不新增测试套件。
