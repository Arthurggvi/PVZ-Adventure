# 石像僵尸实装计划（2026-11-19）

## 目标与已确认需求

复用已确认的 V3 石像及程序化厚度碎块，接入正式 Godot 战斗。石壳固定 3000 生命，不受阶级放大；破壳命中的余伤截断。按真实地块全场随机选择第 4 列及以后，保留有植物格与水格，入场后静止承伤，破碎后生成同阶普通僵尸。只做本地提交，不推送。

## 实现边界

- 保留工作区原有未提交更改；本次仅修改角色注册、专属脚本/场景/素材、卡牌与图鉴、现有刷怪与波次交接接口。
- 沿用 CharacterRegistry、AllCards、ZombieManager 和现有惰性资源加载，不增加全局刷怪器或资源缓存。
- 不调整旧关卡平衡和现有技能资源；新物种可由既有卡牌与波次 API 生成。
- 新源码文件不超过 200 行，按工程规则补中文声明/参数注释。

## 任务与不变量

1. 专用生命和移动组件：固定壳血；所有正常伤害模式经既有路由；禁止行走、啃咬、强制位移；重复命中只转换一次；清场/推车等强制移除不额外生成。
2. 正式出生与转换：入树前按 Board 地块选列 >= 3 的有效脚点/行；转换先创建同阶满血普僵，再交接波次名单和人数并退出旧形态。无死亡档案、亡语、重复掉落、双重阶级缩放。
3. 波次预算：壳与封存本体分清；转换不丢失当前波残血信号、不重复扣减预算，不产生暂时零敌人导致胜利。
4. 视觉：静态无眼石像；短地尘入场；12 个离线分区的正背侧面投影，碎块各自翻转受重力落地，脱离僵尸且限时回收。
5. 数据与展示：追加稳定枚举编号 28、懒加载场景、单卡模板和自动生成 manifest、固定 3000 的图鉴说明；展示模式不得触发实战随机落点或转换。

## 验证与交付

- 首先检查资源导入、脚本解析、manifest 一致性及已有相关加载验收；按 AGENTS 使用项目数据盘上的隔离用户目录，超时和日志上限均有界。
- 以正式战斗和真实生成/受伤入口验证 1–5 阶、3000 临界/超额/穿透/真实伤害、连击/强制移除、静止、随机格含水、转换与波次交接。
- 使用真实 Godot 视口录制入场、静止挡弹、破壳和同阶普僵动作；FFmpeg 编码为移动端可播 MP4，上传 Catbox 并回读校验。
- 保存精简验证记录和少量代表帧，清理临时帧、隔离档案与诊断输出；提交仅本次文件，最终报告实际覆盖与未覆盖边界。
