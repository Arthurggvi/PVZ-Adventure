# 玩家角色与装备系统

用户批准：沿用聊天中的独立装备域方案，接入现有工具栏和统一存档；界面左立绘/等级、右装备槽/装备背包。成长公式 E(L)=round100(1500×1.10^(L−1))。

## 架构
- AdventureState 新增 PlayerEquipmentState；装备 UID、定义 ID 和槽位引用独立于 items。新旧档通过缺省装备域兼容；存在但非法的域拒绝加载。SaveService 仍是唯一保存入口。
- EquipmentDefinition/EquipmentCatalog 描述只读资源；EquipmentService 只操作注入状态；PlayerTransaction 校验档案身份、保存及失败回滚。
- PlayerProgression 统一经验与等级。累计经验为权威，等级为兼容缓存；加载旧档时按经验归一化。任务领奖同时回滚经验、等级和任务记录。
- PlayerEffects 为普通数值/能力快照；AdventureSession 确认选卡时冻结，普通接噩梦沿用，退出/重试清理。不让战斗查装备 ID。
- 双倍经验用于现有任务经验奖励；双倍掉落仅将可随机获取的材料/消耗品数量翻倍，徽章提高这些条目的独立概率或战场金币数值。不加倍首通、保底补发、钥匙、配方和任务物品。
- 冒险战斗按本局装备及其期限自动收集。阳光、金币、材料及花园植物礼盒由对应装备触发，手动点击共用拾取和入账逻辑。
- 工具栏收敛为一个当前模态窗口；角色窗口读取服务快照，切档/切场释放。原任务教学通过统一窗口查询保留能力。

## 本次实现默认值
- E(L) 为 L→L+1 单级需求，正数四舍五入到百位，前三级需求 1500、1700、1800。累计经验上限沿用 JSON 安全整数；可计算等级上限由该数值范围决定。
- 双倍经验卡与双倍掉落卡自取得起有效 168 小时，装备且有效时生效。旧档中没有期限的双倍卡在首次加载时开始计时并保存期限。
- 六个专用槽：时装、经验卡、掉落卡、徽章、阳光收集器、掉落收集器。幸运徽章和财富徽章分别加成掉落概率和金币，冒险者徽章仅作装饰。
- 新获得的两种收集器从取得起有效 168 小时，旧档没有期限的收集器保留永久属性。限时装备按 UID 保存期限，到期即失效，保留在背包中供确认丢弃。详情只显示红色剩余天数，向上取整。
- 无主动出售、强化、交易、购买或装备掉落经济配置；提供统一授予事务供后续奖励/商店接入，不在打开窗口时赠送资产。
- 默认外观不占有物品；立绘由表现资源提供，不实例化带业务脚本的角色场景。

## 备选方案
共用 items 数量库存按分类展示改动更小，但混淆装备身份和普通消耗数量；采用独立装备域，保存仍在同一档案内。不搭建通用插件/任意脚本效果框架。

## 验证边界
遵循 AGENTS.md，不新增不运行测试。使用 Godot 编辑器脚本解析、资源导入和差异检查；检查事务失败、切档失效、旧档恢复、重复结算和原版模式隔离。当前工作区包含用户未提交改动，保留不提交。

## 角色表现与获取入口
- 等级角标原样复用美食大战老鼠 1–80 级图，原图含数字；更高等级使用文字，成长上限不受美术数量影响。
- 时装通过切换立绘贴图表现。双倍掉落卡和冒险者徽章复用美食大战老鼠图标，其余装备使用项目现有图标。
- 开发控制台新增角色装备页，通过正式事务授予装备和设置等级；未配置商店、装备掉落或登录赠送。

## 角色面板交互与素材复用
- 筛选框与下拉菜单复用背包 filter_field 和羊皮纸纹理，普通菜单条目不显示系统单选圆点。
- 装备库存与已装备槽直接复用 InventoryTile 的普通、悬停、选中素材；以纯图标投影接入，不把装备注册进普通道具目录。库存默认铺满 8 列 4 行，数量增加后按完整行滚动。
- 未选择装备时描述与操作按钮隐藏。有效装备显示详情和装备或卸下操作，过期装备显示过期角标与丢弃操作，并复用背包确认弹窗。
- 加成摘要移至立绘悬停提示，静止 0.7 秒显示；移动重置计时，移出、点击、按键、失焦、隐藏收起。计时器归窗口所有，不受游戏倍速影响。
- API 对照：[Control](https://docs.godotengine.org/en/stable/classes/class_control.html)、[PopupMenu](https://docs.godotengine.org/en/stable/classes/class_popupmenu.html)。
