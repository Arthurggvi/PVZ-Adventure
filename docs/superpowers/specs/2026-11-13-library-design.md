# 图书馆设计

主菜单图书馆建筑进入独立三分页面板，底部图鉴保留。沿用 Godot、木框/羊皮纸与已有转职书美术，避免新依赖及重复物品目录。

## 规则

- 今日书籍：每个本机自然日生成五个独立货位；等阶概率 39.5% / 27.6% / 19.4% / 13.5%，各阶内技能书等概率。价格 10000 / 30000 / 60000 / 100000 金币。
- 3000 金币整批刷新，允许同种书重复出现；每个货位只能购买一次，购买后不补货。
- 转换：两本同阶技能书，随机生成同阶书，排除所有投入书 ID，不限制物种。
- 合成：三本同物种同阶书（技能可以不同），随机生成同物种下一阶书；四阶不可投入。
- 后两项不额外收金币。结果入现有背包。
- 五个货位、售罄状态、日期及刷新序号按档案持久化。旧档缺字段时初始化；时间倒退不白送刷新。

## 架构与取舍

采用独立图书馆服务和面板，复用现有目录、库存和存档接口。直接扩充研究室会混淆入口及购买职责；另建物品库存会引入多份资产真相，两者均不采用。

状态编解码不依赖 UI；纯规则负责候选池、概率及材料限制；服务负责资产事务、失败回滚和旧货位拦截；视图负责布局，窗口负责生命周期及交互。金币变化信号可能重入，服务须共用事务锁。

## 表现与边界

今日页使用五张书卡；转换/合成左侧为可筛选书籍网格，右侧材料槽及结果预览。常驻文案仅标签、价格、数量和一行规则，技能说明使用悬停。库存不足、材料过期、切档、跨日及存档失败均不损失资产。由实现者选择具体尺寸、色彩和提示动效。
