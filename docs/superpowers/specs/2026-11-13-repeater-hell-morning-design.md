# 双发射手四种转职弹视觉重制

用户要求替换当前廉价、混乱的转职特效。此次直接改进现有 Godot 视觉层，设计细节由实现方决定。

- 地狱：熔火边缘、紧凑暗核、倾斜吸积盘、向内卷动的火丝与灰烬，裂隙展开后在五秒生命周期末坍缩。
- 晨星：金白星核、蓝紫彗尾，命中时短促闪光、五向锋利星芒、彩色星尘依次展开；分裂弹使用相同视觉语言并降低光量。
- 辉夜：冰蓝双星冠、带暗部的青紫星云、三股体积旋臂与银白星核；保留24枚接触核的原始随机参数和精确轨迹。
- 冥弹：墨色刃影、银白裂丝、青紫幽烟、空间斩痕；处决表现为银光定格、幽影裂解和魂屑升散，保留原身体裁切和层级。
- 明亮原生草地仍能辨认弹体；大面积光晕保持透明，主亮点与暗部之间有清晰层级。
- 不改变碰撞、伤害、持续时间、分裂数量、随机战斗结果；命中画布使用正确弹体绘制深度。

## 方案

保留现有贴图并单纯增亮无法解决扁平圆雾和卡通星屑的形态问题；大量独立粒子又会扩大密集战斗开销。采用原生贴图重着色、有限尾迹几何与单画布解析着色器组合，沿用场景对象池和视觉预算。

## 验收边界

遵守仓库不新增、不运行测试的约定。隔离美术工程直接加载正式视觉源文件，用原生渲染器输出过程画面；人工检查单次、重叠、入场和退出。该过程不代替完整战斗回归或性能测试。仅提交本次视觉及说明文件，不推送。
