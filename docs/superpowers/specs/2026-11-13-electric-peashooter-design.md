# 电能豌豆接入设计

用户要求新增 PVZ2 电能豌豆，复用原版素材、美术、动画和行动逻辑；追加要求是各等阶沿用闪电芦苇的换色方法。

## 实现选择

沿用当前 Godot 植物生命周期和卡片体系，将国际版 6.1.1 的原始 PAM、图集、音效、属性转换到项目中。原版慢速穿透电球与附近放电使用独立弹体逻辑，共用项目的伤害、出战快照和棋盘有效性接口。普通豌豆换皮和闪电芦苇攻击替代都不符合用户指定的原版复用要求。

稳定编号为 52，英文索引为 ElectricPeashooter，中文为电能豌豆。加入选卡目录、图鉴、背包描述、研究室配方及已有材料匹配的配方掉落池。沿用现有冒险模式升级规则，不另建存档或赠送库存。

一阶使用原画；二至五阶直接共用闪电芦苇色表、着色器、根部渐变与特效材质。场上植株、卡面、图鉴、电球、电弧和命中特效的阶级从同一冻结卡片读取。

原版参数以提取的数据为依据，动作发射时刻以 PAM 的事件标记为依据。PVZ2 的原版资源转换保留动作，不声称能够复用其闭源游戏源码。项目未提供的全局机制不另建第二套玩法系统。
