# PVZ-Adventure v1.1.2 更新说明

2026 年 11 月 22 日 · Windows x64 / Android

## 加载与反馈

- Android 将进入场景和打开功能窗口时的资源读取分散到多个帧。桌面继续使用后台加载，并改进取消、超时和请求回收。
- 桌面连续加载同一项资源超过 3 秒时，会显示资源名和耗时。加载异常可在设置里复制记录。若上次加载中断，重开游戏后可在主菜单复制上次的加载记录。

## 道具与皮肤

- 更新「挚爱之章」和「英灵殿 · 神殿之光」的存档绑定，新增神殿之光三号、四号。
- 装备「神殿之光」后，战斗中的头像和角色技能区使用专属外框、背景和光效。战斗头像及角色技能显示同步放大。

## 界面与战斗

- 修复图鉴滚动并支持触屏滑动，调整蹦极僵尸的取景和橄榄球僵尸的背旗显示。
- 重排选卡时的植物转职预览，精简普通僵尸的步行动画，并优化闪电芦苇的索敌。

正式版启程页开放海滨城镇和僵尸岛，奇境大陆入口继续关闭。
