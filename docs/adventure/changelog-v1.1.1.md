# PVZ-Adventure v1.1.1 更新说明

2026 年 11 月 22 日

- Windows 和 Android 均可在设置中直接导出当前冒险存档。
- 新增渲染兼容模式和 8 秒自测。五星至十星星章使用预烘焙动画，开启兼容模式后显示静态星章。
- 战斗中可点击左上角头像释放角色技能，手机上也可用双指张开手势。桌面新增二倍速快捷键，并支持将战斗快捷键绑定到鼠标侧键。
- 冒险选卡可查看植物的转职路线、阶数和技能。关卡预览支持手动滚动，并突出显示可能掉落的配方。
- 背包支持一键整理并记住排列。研究室新增强化历史，图鉴新增状态说明和效果演示。
- 更新没落营地、墓地下游和埃德加神殿的配乐，修复资源加载卡住及通关返回地图后界面未恢复的问题。
- 「冻结海洋」的冷却由 90 秒缩短至 45 秒，「阳光雨」的冷却由 90 秒延长至 150 秒。
