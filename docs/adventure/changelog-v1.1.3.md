# PVZ-Adventure v1.1.3 更新说明

2026 年 11 月 24 日 · Windows x64 / Android

## 加载与资源回收

- 角色和战斗场景资源按本局复用，离开战场时释放。切场、工具栏和背包只在内容准备和交接期间持有临时资源。
- 选卡与研究室按需生成植物卡预览。图鉴优先加载可见头像，滚出可见范围后回收，详情在打开时加载。
- 过场保留正在显示的场景，等目标场景准备好以后再交接。短音效缓存设有条目和容量上限，缓存回收不会中断已开始播放的音效。

## 战斗表现与性能

- 精简普通、读报和橄榄球僵尸的常规动画轨道，烧焦表现按需加载和回收。
- 将闪电芦苇的电弧和命中特效合批绘制，减少激荡伤害结算与回旋镖索敌的重复计算。
- 战斗环境效果强度归零时暂停相关视口和背景复制，效果恢复时重新启用绘制。

## 界面与玩法

- Boss 图鉴收录妇人（凯莱赫），可查看双阶段资料与技能预览。
- 研究室复用植物卡的悬停预览，并保护最后一张荷叶，避免它在强化时被消耗。
- 新增或补齐缠绕海草、魅惑菇、毁灭菇、窝瓜、三线射手、高坚果、仙人掌、杨桃、卷心菜投手、玉米投手和西瓜投手的四阶转职。
- 重做阳光菇的转职与月光蔓延，调整大喷菇、胆小菇和寒冰菇的转职效果。
- 调整玉米炮落地爆裂与余震、杨桃星弹的碰撞和退场，以及樱桃炸弹和火爆辣椒对僵王的爆炸伤害。
- 调整战斗内外档案头像的取景和渐隐，修复魅惑伴舞在阶段切换时的行走抖动。
- 修复双发射手分裂星弹和石像移动组件在发行导出中的脚本编译错误。

正式版启程页开放海滨城镇和僵尸岛。奇境大陆继续在开发分支迭代。
