# 石像僵尸：实装与验证记录

日期：2026-11-19。项目：PVZ-Adventure；Godot 4.7.2，Windows，OpenGL Compatibility，RTX 5060 Laptop。

## 已实现行为

- 物种编号 `CharacterRegistry.ZombieType.Z028StoneStatue = 28`，正式场景 `res://scenes/character/zombie/zombie_stone_statue.tscn`。
- 1—5 阶石壳都固定 3000 生命。壳与后续普通僵尸是独立实体；击碎攻击最多扣除石壳剩余生命，余伤不转移。破壳后同一帧继续命中旧壳不会重复换体。
- 实战出生从当前 `BoardRuntime` 的真实有效格等概率选取，零基列号至少为 3，即第 4 列起；包含水格与已有植物的格子。无有效格时创建失败并返回空值，不回退到前三列。
- 出生有短地尘与地裂表现；石像原地承伤，不行走、不啃咬，不接受推移、击飞或恐惧位移。真实碰撞和受击仍沿用原战斗组件。
- 破壳在当前伤害调用退出后延迟换体；新普僵先正式登记，再交接波次名单、掉血监听和自然出怪归属，最后注销石像。保留所在行、脚点、等阶、迷你模式、敌我模式及原波次。
- 正常破壳不触发旧石像的击杀、死亡掉落或致死前观察。清场、碾压、拖入水下等强制移除优先，不额外释放普僵；跨战场、跨轮次和跨阶段的迟到回调会取消。
- 自然波次生命预算包括石壳与封存普僵，实际伤害组件只包含石壳。破壳不会重复增减本体预算，也不会因旧体先移除而出现暂时零敌人。
- 卡牌、惰性目录、图鉴及展示模式已接入。旧关卡的随机池和波次权重未改变；关卡可通过现有波次配置或角色创建入口使用编号 28。

## 视觉与成本

使用已确认的无眼石像素材及 12 个预切碎块；碎块由正面、背面和侧面组成，在 2D 画布中投影，分别翻转、受重力并按旋转后的最低点接触地面。主要落地约 0.5 秒，独立碎片节点约 1.2 秒后回收。

核心四份素材合计 158,733 字节，约 155 KiB。未引入 3D 物理引擎或全局可变素材缓存；沿用 Godot 原生资源缓存及工程既有惰性加载入口。

## 验证结果

所有引擎验证均使用数据盘上的独立便携用户目录，并有超时及 8 MiB 日志上限；未使用玩家档案。

| 最终运行 | 检查数 | 失败 | 退出码 | 脚本/引擎错误记录 |
|---|---:|---:|---:|---:|
| 前院 `contracts-day-final` | 150 | 0 | 0 | 0 |
| 泳池 `contracts-pool-v2` | 154 | 0 | 0 | 0 |
| 屋顶 `contracts-roof` | 149 | 0 | 0 | 0 |
| 正式卡牌与五阶展示 `catalog-final` | 87 | 0 | 0 | 0 |
| 实机录像 `runtime-video-final` | 18 | 0 | 0 | 0 |

三种地形共 453 项行为断言；另有 87 项卡牌/展示检查和 18 项录像过程检查。覆盖：

- 五阶、普通/穿透/真实伤害、2999→剩余 1→9999 的临界超额攻击、伤害回执、同帧重复命中、原普通僵尸致死观察兼容。
- 强制清理、待换体时清理、秒杀攻击只破壳、迷你模式石壳仍为 3000、出生满血与身份来源交接。
- 静止 40 帧、禁止攻击及位移；每种地形各 512 次真实随机选择，分别覆盖 30/36/30 个可用格，未落入前三列；验证水格、植物占用格、屋顶及无候选格。
- 通过真实波次入口验证经典/现代刷新：初始 3000+270，扣 2999 后剩 271，破壳交接后继续正确扣除普僵伤害，清理归零；换体时自然僵尸数采样为 `[2, 1]`，未出现 0。
- 正式卡牌身份及头像；五阶 `IsShow` 无实战管理器时不触发入场/破碎；6 个展示节点全部释放。

既有六项启动/加载检查均输出功能 PASS 并以 0 退出：惰性启动、惰性音频、线程场景加载、启动至菜单、线程战斗往返、工具栏弹窗。

**保留的验证边界：**其中无窗口的线程战斗往返检查仍出现 5 条 dummy renderer 的空纹理错误，以及退出时 1 个纹理 RID、2 个 ObjectDB 实例和 1 个资源未释放的告警。该检查未生成石像；本次未定位其原因，不能把它计为无告警通过。上述石像最终 GPU 运行均没有这类记录。本次验证限于 Windows 实机，未执行 Android 导出。

验证过程中实际发现并修复了泳池 `Panel` 行不能调用 `Node2D.to_local()` 的兼容问题，以及碎片纹理绘制参数顺序错误；随后分别以泳池实战与完整录像重新确认。临时验收观察器的闭包引用环也已清除，最终运行无退出资源告警。
