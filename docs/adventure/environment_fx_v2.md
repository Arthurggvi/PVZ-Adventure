# 双地图环境 FX 接入

## 入口与开关

- 主菜单：`scenes/main/01StartMenuV8.tscn` → `ArtCanvas/EnvironmentFX`。
- 僵尸岛：`scenes/adventure/zombie_island.tscn` → 运行时的 `MapCanvas/EnvironmentFX`。
- 两个根脚本均导出 `environment_fx_enabled=true`、`use_clean_sky=true`。
  关闭后者恢复原 PNG 引用并停云；关闭前者隐藏、停止新增 FX 并复原船体。
  既有乌鸦与 BGM 保持原来的生命周期。

## 已接入

- 主菜单：五朵分速云、三层低透明海面高光、六处错峰涟漪、船体微浮动、三个复用烟团节点；保留原有单只乌鸦。
- 僵尸岛：五朵云、三处紫雾、独立相位双瀑布与双水花、毒液流光、四个随机形态/留空周期气泡节点、神殿弱脉冲、四处海岸涟漪。
- 配置集中于 `data/environment/*.json`；共同使用两个小型环境脚本与一个局部遮罩 Shader。
  所有效果是固定数量的 Node2D，位于主体/UI 下方，无 GUI 命中或全局播放器。
- 安装素材只显式追踪运行时所需的 PNG；原始背景没有改写。
  新增海岸遮罩从原 PNG 保守筛选，墓地/脑罩遮罩使用背景局部坐标；生成器为 `tools/build_environment_masks.gd`。

## 用户反馈后的定位修正

- 灯塔：原安装云遮罩用黑色矩形预留塔身，造成云层被直角截断。
  新生成的 `generated_masks/main_sky.png` 按塔顶、檐口、塔身轮廓遮挡，塔外天空保持可通云。
- 船与海：原码头 PNG 在木板之外还保留不透明海水，叠在船体上造成矩形切口。
  新 Alpha 遮罩移除该水块并保留码头结构；船体 Shader 沿下缘 Alpha 添加窄接触水线，随原船体浮动。
  停用原本远离船底、位于 y≈820 的整图船纹层，原 PNG 保留。
- 双瀑布：旧参考截图的纵向位置不适用于真实地图。上段流光改为 `(891,432)` / `(86,90)`，
  下段改为 `(903,724)` / `(108,110)`；两处水花分别定位到真实落点，使用新生成的独立流域遮罩。
- 一次资源导入与针对性图形检查均退出 0；已有轻量检查增加了塔内/塔外、海水/木板、瀑布内/外采样断言。
  只在对应接缝位置做短时画面核对，未进行长时动画或无关战斗回归。

## 强化水纹与临时叶纹补丁

- 复用原有两个 `scenes/environment/*_fx.tscn`，没有新增并行FX系统。
- 主菜单原有三组海面及六组岸纹改用已安装v2强纹素材和 `menu_water_only_mask.png`。
  参数位于主菜单FX场景的 `Ocean overlays`：初始强度0.75，漂移基准10原图像素/秒（各组0.85/1/1.15倍率），岸纹周期4秒。
  遮罩按实际背景显示区的局部原点、尺寸以及精灵当前绘制尺寸，换算为整图归一化UV；节点仍绘制在主体、码头与UI下方。
- 当前两张源背景和设计绘制区均为1920×1080；组件也按源纹理和等比显示区计算换算，未使用窗口尺寸作遮罩坐标。
- 两个FX场景的 `Provisional leaf texture wind` 启用候选遮罩内纹理采样偏移（主菜单2像素、岛上1.5像素）。
  不移动顶点或背景节点；源、目标采样都受叶片遮罩约束。它仅是临时叶片纹理风动，未完成分离树冠或物理摆动。
- 僵尸岛未配置新海水遮罩，沿用v1海岸效果；不自动启用未经验证的僵尸岛海水遮罩。
- 本轮只作一次Godot资源导入/解析检查与文件差异检查，不录屏、不截图、不做主观画面结论或玩家/战斗回归。
  导入退出0，无Script/Shader错误；仍有原资源的重复/失效UID警告。
- 修改文件：`scenes/environment/main_menu_fx.tscn`、`zombie_island_fx.tscn`；
  `scripts/environment/environment_layer.gd`、`environment_sprite.gd`；`data/environment/main_menu.json`；本记录。
  显式追踪已安装v2中的9张强水纹、3张遮罩及 `leaf_wind_provisional.gdshader`（含UID），未复制或重画美术。
