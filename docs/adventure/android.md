# Android 整备

Android 预设使用 Godot 4.7.2 stable 的标准模板，沿用横屏、GL Compatibility 和 ETC2/ASTC 导入。预设同时包含 ARMv7、ARM64 和 x86_64，Android 自动选择原生架构；手机与常见 64 位模拟器共用一个 APK，不要求玩家选择型号或手动切换渲染器。应用 ID 为 `io.github.arthurggvi.pvzadventure`，正式版本为 1.1.3（版本代码 11）。启程页开放僵尸岛与城镇，奇境大陆在开发环境中继续迭代。

Android 以 1066 × 600 为布局坐标，2D 内容按屏幕上游戏区域的像素绘制。宽屏手机和平板等比留边，保留完整的棋盘和功能栏。启动时默认全屏，可在设置页显示系统栏，或再次切回全屏。

在编辑器设置的「导出 → Android」配置 JDK 17 和 Android SDK，在模板管理器安装与编辑器一致的模板。新检出需补齐本地的原版运行贴图、音效和字体。导入后，使用「项目 → 导出 → Android」，关闭调试导出并使用项目的发布密钥。签名文件和 `export_credentials.cfg` 留在本机。已装同包名的调试版需要先备份档案，再更换安装。

## 操作核对

- 在海滨建档、启程和打开工具栏。系统返回键先关闭当前弹窗或取消操作，在海滨无弹窗时打开保存退出确认。切至后台会保存已加载的玩家档案。
- 地图使用单指拖动和点选。战斗中点选卡片后点格子种植，点阳光或钱币拾取，点工具图标使用铲子和手套。持卡或工具时，点有掉落物的格子优先操作该格。种植失败会响起提示音，仍可持卡改点其他格子。再次点选已拿起的卡片或铲子可取消。战斗中没有持有物时，返回键切换暂停菜单。
- 触屏选中铲子时，槽内图标保留并高亮。检查点选、再次点选收回、返回键收回和点格铲除是否与同一个手持状态一致。
- 空手时在战场滑过阳光、金币、材料或礼盒即可拾取。滑动使用引擎选中的触点和战斗按钮共用的映射坐标，命中范围每边放宽 8 个游戏逻辑像素，快速划过和贴边滑动仍可收取。选卡、持工具、暂停、切场和 GUI 遮挡会中止手势，抬手、取消和退后台后不能续接旧触点。奖杯仍需明确点击。
- 研究室可用触摸选择及清空工作槽。设置页可调音量和全屏，关闭全屏后可核对系统栏、挖孔边缘与触点位置。再检查拖放、弹窗优先级、后台恢复与档案加载。

## 正式包启动验证

保留 `00Bootstrap → SceneTransition → 01StartMenuCoastal` 和既有卡牌/角色/音效惰性加载，不通过同步预载绕过启动问题。Android 日志中的 `bootstrap_ready` 表示引擎 Autoload 后进入轻量首屏，`menu_interactive` 表示菜单已绘制并释放遮幕；后者的 `card_catalog_materialized=false` 用于核对菜单未装配战斗卡牌。两个时刻不能混算为同一项加载耗时。

必须运行正式模板导出的 APK 并检查 logcat。编辑器和调试模板不能暴露正式模板对节点自身 `free()` 的解析差异；相关离树节点改用帧末 `queue_free()`，不改变角色、卡牌或音效的按需加载策略。

冷启动及地图返回城镇都由同一个过渡批次预读城镇贴图目录。验收要走到战斗、返回地图，再从地区选择器回城，等待遮幕解除、确认合成画面有内容，并实测战斗工具时的触摸输入。
