# PVZ-Adventure

《植物大战僵尸》的非商业单机同人项目。从海滨港口启程，探索僵尸岛的六个关卡。

## 在 Windows 上开始玩

1. 完整解压 Windows x64 ZIP，打开 `PVZ-Adventure.exe`。同名 `.pck` 需放在同一目录。
2. 首次启动时创建档案，在列表选中后确认。点击海滨右侧的「启程」，选择僵尸岛。
3. 完成戴夫引导领取初始卡片。在草坪选卡开战。点击卡片和格子种植，点击场上阳光收集。右上角菜单用于暂停、重开和返回地图。
4. 通关普通阶段开放下一关。满足条件且持有对应钥匙时，可在结算选择续战。右下角工具栏提供背包、任务、图鉴、角色和研究室，入口随档案和任务开放。

Windows 存档默认位于 `%APPDATA%\Godot\app_userdata\GodotPVZ-Dream`。左上角可切换档案，主菜单确认退出时会保存当前档案。

## 1.0.1

奇境大陆在 `develop` 分支继续开发。

- 调整首通金币雨的落点与节奏，金币落稳后显示续战提示或奖杯。
- 修正游泳僵尸的死亡演出，以及缠绕水草的拖拽动画和音效。

## 1.0.0 正式版

- 新增戴夫商店、图书馆每日书目和埃德加钥匙任务。埃德加神殿配置了双首领与终末续战。
- 新增闪电芦苇，扩展寒冰射手、电能豌豆、寒冰菇和火爆辣椒的转职，更新樱桃炸弹的转职表现。
- 战斗加入用于搬移植物的手套和二倍速按钮。旗帜波清场时有机会掉落配方，结算奖杯保留配方保底。
- 启动、地区导航和战斗切换采用异步资源准备，背包、研究室与图鉴按需构建可见内容。
- 修复研究室配方耗尽后的选择状态，以及工具栏面板切换和退出确认。
