NATIVE GODOT IMPLEMENTATION
Original PAM data is 30 FPS, 612 frames; 7 source actions:
idle 0-99 (100); walk 100-189 (90); eat 190-448 (259); run 449-468 (20);
tackle 469-507 (39); kick 508-555 (48); die 556-610 (55).
Source frame 470 triggers the named tackle SFX event; source frame 474 is use_action;
animation event is attached to the frame corresponding to game damage.
37 independently cropped original sprite textures, 47 reusable Sprite2D slots,
native AnimationPlayer tracks with source-defined 30FPS authored transforms.
Every slot is bound to a stable PAM reference instance path per action.
Unused slots have explicit hidden keys so switching clips cannot retain parts.
The visual scene stores an authored idle pose for static portraits. The live
helmet track drives the head anchor. The original `particle_head` sprite is
detached at that pose on ordinary death while the headless `die` clip plays.
The tackle impact uses the source alpha key at frame 477. Project chew feedback
is keyed to the closed-mouth poses in the original eat clip.
PAM frame element records encode *sparse transforms*, not a complete list of
visible parts: an attached part keeps its last pose until removed/replaced.
Source draw order controls z_index. Empty terminal stop markers keep the
final visible pose. This preserves feet during eat (190-448), idle, and death.
One stale duplicate shoe in walk is retired by the converter's general
superseded-instance handoff rule when an identical moving shoe replaces it
at original frame 169; see original_source_manifest.json.
Tackle's hit event is from original frame 474 and simultaneously resumes
spent locomotion (0.64 base speed), while the recovery clip keeps playing.
Rendering can interpolate between source keyframes like native project zombies.
Unused source visual status overlays (butter, ink, ground) are deliberately excluded.
Only source instances with an initialized pose are rendered; subsequent
sparse frames carry their previous pose. Bitmap anchor offsets use the
positive original PAM offset convention.

The source uniform was RED. The requested BLACK version changes only palette/appearance,
and preserves original game component geometry, frame sequencing and choreography.
The original red texture atlas and PAM evidence remain outside the game at
D:/Dev/PvZ/_review/all_star/pvz2_original_5_8_1/original_allstar_source/.
Only the black palette adaptation required at runtime ships in original/black.

Original gameplay configuration: `Packages/PropertySheets.rton`,
`ZombieModernAllStarDefault` (referenced by `modern_allstar` in
`Packages/ZombieTypes.rton`). Hitpoints 1600, EatDPS 150, SmashDamage 1500,
Speed 0.16 and RunningSpeedScale 0.5. The sheet assigns no independent
helmet armor. Movement uses the project scale of approximately 80 pixels
per tile and a 20-pixel-per-second base component speed.
