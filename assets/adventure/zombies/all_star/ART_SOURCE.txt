ORIGINAL PVZ2 ALL-STAR REFERENCE (SEPARATE FROM IMPLEMENTED ART):
https://plantsvszombies.wiki.gg/wiki/All-Star_Zombie
- PvZ2 internal codename: modern_allstar.
- PvZ2 health: 1100 (current version in this reference).
- Charges until first eligible plant is tackled; afterwards switches to slow movement/normal eating. Can kick Super-Fan Imps.
https://www.9game.cn/zwdzjs2/1876834.html (2017 third-party game data summary, NOT extracted primary configuration)
- Charge 0.5 tile/second; normal 0.16 tile/second (speed ratio 3.125).
- In this project's grass board each column is about 80px, and MoveComponent's base speed is 20px/second; therefore project multipliers are CHARGE_SPEED=2.0 (40px/sec) and SPENT_SPEED=0.64 (12.8px/sec).
- Calibration is approximate: global or random zombie speed factors still apply; no primary PvZ2 executable/config was extracted to confirm the two reported speeds.
https://www.spriters-resource.com/mobile/plantsvszombies2/asset/215268/
- External ripped PvZ2 International assembled actions: Death 55 PNGs, Running 20, Tackle 39, Walking 24, Kick 48, Idle 100. There is a separately named Eating sequence. PNG counts are NOT native action times or engine FPS. They also demonstrate that PvZ2 All-Star's walk and run are distinct animations.
- The complete ripped pack has NOT been downloaded successfully from the site (HTTP 403). Thus these clips have NOT been installed. In this project walk still uses a retimed third-party mod run sequence and is not fully accepted as a match.
https://github.com/apples1949/PvZ2ModdingGuide/blob/master/document/chinese.md
- Original PvZ2 PAM animation format is frame-based and does NOT auto-interpolate. PAM supports frame action commands. Its original animation frame rate and All-Star event frame have NOT yet been verified from a primary PAM file.
