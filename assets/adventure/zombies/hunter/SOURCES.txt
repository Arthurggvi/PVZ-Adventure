Production image processing: only the supplied international assembled frames and split images are used. Images were resized to exactly 0.5 (transparent padding for odd dimensions), cropped only in transparent areas and packed into PNG atlases no larger than 2048 per side. Every original frame and its order is retained. Duplicate bitmap storage is shared without dropping sequence entries. No image generation, painting, invented intermediate animation or replacement pixels was used. Portrait uses the first idle frame. The four snowball images are existing split images, not procedurally painted shapes.

Timing: all five source-site GIF previews have the same number of frames as their PNG sequences. Each GIF frame has a 30 ms duration: idle 63/1.89 s; walk 90/2.70 s; eat 121/3.63 s; throw 63/1.89 s; death 65/1.95 s. animations.json records the exact GIF URLs. This preserves the uploader preview timing; the original PAM timebase and animation commands were not supplied.

Registration and release event: action foot points are fixed from original first frames, using measured feet ROIs that exclude the bone. See animations.json. Source throw0025 still holds its snowball; throw0026 first shows an empty forward hand, therefore release is placed at zero-based frame 25, 0.75 seconds. The hand anchor is an approximate image-space measurement. These are documented integration choices, not claimed original skeleton/event metadata.

Damage artwork: the original death sequence is already headless and lacks the bone-holding arm. The original split parts contain separate limbs, but the ZIP has no original PAM rig or assembled armless walking/eating/throwing sequences. Those missing sequences were not fabricated.

Audio provenance: the Hunter Zombie audio table identifies Throwingsnowball1-3.ogg (throw effort), Snowballthrown1-2.ogg (snowball release), Snowballhit1-3.ogg (plant impact), Hunterded1-2.ogg (death).
Audio table: https://plantsvszombies.fandom.com/wiki/Hunter_Zombie#Audio
Public original file pages and exact public media CDN URLs are recorded per file in animations.json. OGGs are copied byte-for-byte, without resynthesis, recompression or pitch shifting. No separately labelled idle/walking Hunter groan was located, so no clip is mislabelled as one.
