# 石像僵尸正式美术

五款石壳来自用户提供的四张透明图。每只石像出生时独立等概率抽取一次，裂纹与破壳碎石使用抽中的同款图集。卡面使用第一款。

- `skin_hollow` 取自第一张单人图。
- `skin_howling` 与 `skin_faceless` 分别取自第二张合图的左、右人物。
- `skin_split_face` 取自第三张单人图。
- `skin_chiseled` 取自第四张单人图。

素材等比缩放到 166 × 260 透明画布，统一有效高度约 248 像素，并将前脚鞋底配准至约 (114, 251)。石像视觉仍使用 (80/166, 125/260) 的缩放及 (-52.8, -110.7) 的偏移，继承角色朝向和游戏内脚点。

同名前缀的 PNG 与 JSON 成对使用。PNG 中的 (2, 2, 166, 260) 区域是完整壳面，(172, 2, 166, 260) 区域是受损裂纹，其余区域存放 12 块碎石的正面和背面。裂纹与各款碎石轮廓按自身外形烘焙。JSON 保存区域、位置、轮廓、厚度和背面形状。运行时纹理由 Godot 资源缓存复用。
